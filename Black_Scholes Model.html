SKILL IN PRACTICE

Financial modelling

This browser calculator implements the dividend-adjusted Black–Scholes equations for European calls and puts. It handles expiry using intrinsic value and zero volatility using discounted deterministic payoff.

C = S e−qT N(d₁) − K e−rT N(d₂)
P = K e−rT N(−d₂) − S e−qT N(−d₁)

Assumptions include constant volatility, constant rates and continuous dividend yield, frictionless markets and European exercise. Inputs are manual; this demo does not retrieve live option chains or estimate implied volatility.

SKILL IN PRACTICE

The chart recalculates call and put values across underlying prices while keeping the remaining inputs fixed. It is a model sensitivity curve, not a forecast or volatility-skew chart.
